PENGERTIAN
Mengantisipasi Down Time Mesin Server SIM RS seminimal mungkin dengan mengalihkan ke mesin server backup SIM RS
TUJUAN
Sebagai acuan penerapan langkah – langkah dalam melaksanakan Down Time Server RS.
KEBIJAKAN
Keputusan Direktur Rumah Sakit Nur Rohmah tentang pelayanan Unit Umum.
PROSEDUR
Petugas IT memastikan bahwa server SIM & jaringan komputer dalam keadaan online dan terhubung.
Bila ternyata komputer server SIMRS down/mati maka petugas IT melakukan langkah – langkah untuk meminimalkan waktu down time atau off line nya komputer server SIMRS sbb :
Melakukan perbaikan komputer server Sim RS
Jika dalam waktu 1 jam perbaikan belum berhasil maka dilakukanlah take over ke server backup.
Selama proses penanganan Down Time Komputer Server Sim RS, Unit pelayanan menggunakan sistem manual sesuai dengan SPO manual di unit masing-masing.
